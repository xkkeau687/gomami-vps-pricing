## 三网去程和回程不对称，这点很少有人讲

大部分测评只测回程，因为回程决定你打开网页有多快。但如果你要往新加坡上传东西——备份、部署、推流、跑同步——去程的线路同样算数。

SIN Pulse 的回程是三网各自精品：电信 CN2 GIA 经香港 CTGNet 入境，联通 AS9929 经广州和上海入境，移动 CMIN2 经广州入境。去程则走三网各自的普通主干：电信 163、联通 10099、移动 CMI。这种“回程优化、去程主干”的组合在同价位里很常见，说清楚比含糊带过有用。

回程延迟的实测区间大致是：

| 运营商 | 回程线路 | 典型城市延迟 |
| --- | --- | --- |
| 电信 | CN2 GIA（AS4809） | 广州 40–50ms，上海 60–70ms |
| 联通 | AS9929 | 上海 66–70ms，北京 73–78ms |
| 移动 | CMIN2（AS58807） | 广州 38–42ms，北京/上海 70–85ms |

带宽方面，第三方在深圳电信 8 线程测得 922/888 Mbits、延迟 50.7ms，江苏移动 8 线程 906/871 Mbits、延迟 81.6ms。晚高峰（20:00–23:00）的独立测试里，电信和联通表现稳定，移动比同类跨网 CN2 方案更稳；电信在部分节点会略慢于个别竞品，不算特别稳。
